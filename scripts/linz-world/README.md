# Linz World Scripts

This directory contains scripts that exercise Linz World business flows rather
than generic Hermes maintenance tasks.

- `linz_bubble_mrk_flow_test.py`: Bubble/MRK smoke and real agent-flow test.
- `formal_experiment_prepare.sh`: formal experiment preflight.
- `formal_experiment_run.sh`: formal experiment event runner.
- `formal_experiment_export.py`: formal experiment export entrypoint.
- `formal_experiment_lib.py`: shared implementation for formal experiments.
- `formal_experiment_report.py`: report renderer for formal experiment output.
